Fake News Detection Using Machine Learning

About the Project

This project uses Machine Learning to classify news text as FAKE NEWS or REAL NEWS. It uses TF-IDF for text vectorization and Logistic Regression for classification.

Technologies Used

- Python
- Machine Learning
- Scikit-learn
- TF-IDF Vectorization
- Logistic Regression
- Flask
- HTML, CSS, JavaScript
- Google Colab

Features

- Accepts news text from the user
- Processes the input text
- Predicts whether the text is fake or real
- Provides a simple web interface

Project Workflow

News Text → Text Preprocessing → TF-IDF → Logistic Regression → Prediction

Disclaimer

Predictions are generated by a trained machine learning model and may be incorrect. The application does not independently verify news against live sources.
